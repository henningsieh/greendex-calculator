# Cost Tracker domain model

The current model is defined by these sources:

- [Cost Tracking glossary](../GLOSSARY.md) defines the business terms.
- [Current domain behavior](domain-behavior.md) describes participation, Participant Onboarding, journeys, Claims, and payouts.
- [Claim workflow](claim-workflow.md) describes submission, review, correction, approval, rejection, and payment.
- [Shared Project model](../../../docs/projects/model.md) and [permissions](../../../docs/projects/permissions.md) define shared relationships and authority.
- [Accepted ADRs](../../../docs/adr/README.md) record the decisions behind those rules.
- [Application architecture](architecture.md) maps that behavior to source ownership.

The former Cost Submission schema blueprint is [archived](archive/cost-submission-blueprint.md). Its aggregate, submission-window gates, and unauthenticated entry model are not current implementation guidance.
